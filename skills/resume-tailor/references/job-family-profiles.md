# Job Family Profiles

Use these profiles to bias project selection and keyword coverage.

## Java backend

Prioritize:

- Spring Boot / Spring Cloud / Nacos / Dubbo
- MySQL / PostgreSQL / Redis / MQ
- transactions, idempotency, concurrency, observability
- service decomposition and API contracts

## Payment / trading

Prioritize:

- payment order, transaction flow, callback, refund, reconciliation
- idempotency, state machine, compensation, timeout close
- Apple / Google / UseePay / webhook
- data consistency and auditability

## Platform engineering

Prioritize:

- internal tools, code generation, templates, migration
- CI/CD, verification gates, release automation
- developer experience, reuse, rollback, safety boundaries
- measurable cycle-time or manual-step reduction

## Agent engineering

Prioritize:

- Agent Skills, tools, MCP, context management
- multi-agent collaboration and task state
- evidence capture, evaluation, guardrails
- reproducible workflows and versioned instructions

## Full-stack / legacy modernization

Prioritize:

- frontend + backend + packaging
- compatibility with legacy formats and data
- incremental migration, dual-run, rollback
- byte-level or contract-level regression tests
